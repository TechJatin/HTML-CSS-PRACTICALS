Each `LabXX` directory contains the source files and instructions for that exercise. The exact contents may vary by practical.

## Run a Practical

1. Download or clone this repository.
2. Open the required `LabXX` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit `style.css` to experiment with the styling.

No package installation or build step is required for these static HTML/CSS exercises.

## Learning Outcomes

- Build valid HTML document structures.
- Use headings, paragraphs, links, images, lists, forms, and tables.
- Apply CSS selectors, colors, spacing, units, and custom properties.
- Understand the CSS box model.
- Build layouts with Flexbox and Grid.
- Apply media queries for responsive layouts.
- Organize practical source code and manage it with Git.

## GitHub Setup

Create an empty GitHub repository, then run these commands from the project root (replace the URL with your own repository URL):

```bash
git init
git add .
git commit -m "Add HTML and CSS lab practicals"
git branch -M main
git remote add origin https://github.com/TechJatin/HTML-CSS-PRACTICALS.git
git push -u origin main
```

If `origin` already exists, update it with:

```bash
git remote set-url origin https://github.com/TechJatin/html-css-lab-practicals.git
```
